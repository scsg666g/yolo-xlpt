## 这些截图代表什么

截图时开发版只有一个可选训练 Attempt，因此实验对比页没有多运行曲线；至少选择两个运行才会生成对比。数据集页只管理平台上传的数据集，已有任务直接使用 YAML 路径时，该列表仍可能为空。这两张图展示真实的引导状态。

模型测试结果来自已有历史，拍摄时未启动训练或推理。算力页为固定同一时刻的采样，临时暂停了截图浏览器的自动刷新；GPU 负载和在线状态仅代表拍摄时刻。

## 后续更新约定

1. 从准备发布的开发版截图，先核对品牌区与健康接口的版本，等待字体、图表和图片加载完成。
2. 只进行导航、展开、筛选和查看已有记录；不要为截图创建训练、修改真实配置或删除任务。
3. 使用统一主题和宽度；必要时增大视窗高度，不将完整页面缩小到文字无法阅读。
4. 发布前遮挡服务器地址、部署路径和其他敏感信息；不要打开或拍摄 Token、密钥及专属接入配置。
5. 图片使用版本前缀命名，同时更新[项目首页](../../README.md#界面预览)和[Web 说明](../../web/README.md#当前界面导览)中的相对链接。
6. 删除被替换的旧截图并检查全仓引用；保留需要发布的图片，不提交原始未遮挡截图、临时浏览器配置或截图工具缓存。

旧图已从当前文件树删除，历史版本仍可通过 Git 历史查阅。只有将文档、新图片及旧图片删除记录一起提交并推送后，GitHub 仓库首页才会显示更新。
