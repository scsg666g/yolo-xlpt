# 数据集保存位置、传输与文件生命周期（平台 1.5.1 / Agent 2.1.0）

## 页面操作

- 主页面右上角“保存位置”打开配置弹窗，按服务器分组显示真实目录、默认位置及校验空间。检查与设为默认直接操作；启用/禁用、移除配置位于每行的更多菜单。移除配置不会删除文件，服务端仍校验默认位置、数据集与未完成操作的保护规则。
- “操作记录”打开右侧面板，默认显示进行中及失败操作（没有此类记录时显示全部），每页 20 条，支持状态、类型、服务器和名称筛选。点击一行查看路径、错误、进度及可用的重试/取消按钮。迁移可按源或目标服务器查找；查询检查操作时使用保存位置名称。
- 翻页固定创建时间范围，新记录出现时点击提示或“查看最新”更新范围。现有操作的状态持续更新，数量可能随状态筛选而变化；“重置筛选”不删除历史。“关闭”或 Esc 仅关闭面板，不取消后台操作；选择器打开时 Esc 先关闭选择器。
- 主页面仅轮询全量统计和节点信息，打开历史面板后才加载分页记录。页面隐藏时暂停轮询，恢复可见后刷新。失败操作可能继续保护对应文件；应重试或在允许阶段取消，再进行删除等操作。
- 主列表“可删除”与删除预览共用服务端判断；外部登记、被引用及有未完成操作的数据集不会列入可删除。不同服务器相同路径的数据集按稳定编号独立展示。

本次仅调整平台 API 与页面，数据集传输及 Agent 协议保持不变，Agent 2.1.0 无需重新分发。开发版后端需重启以加载新的分页与统计接口。原 `/api/dataset-storage/operations` 接口继续返回最近 200 条供旧客户端使用，新页面读取 `/operations/page` 和 `/operations/summary`，可以浏览全部历史。


本功能管理本机与远程节点上的自包含 YOLO 目标检测数据集；分类、分割、姿态和旋转框任务原有训练接口保持原样，不把检测标签校验器用于其他任务类型。不是对数据文件的自动版本控制：新增数据应另建目录，再上传或复制，不覆盖正在使用的数据集。

## 使用入口

- “设置 → 存储目录”或“数据集管理 → 保存位置”：为每台服务器登记多个具名目录，选择是否创建、校验权限与空间，设为该节点默认位置、启用/禁用或移除空配置。目录检查结果带时间；远程离线时操作排队，恢复 Agent 后继续。保存位置路径不可原地改写；新建位置、迁移数据后再移除旧配置，避免已有任务失去文件。
- “上传数据集”：选择服务器保存位置，再选浏览器文件夹；页面显示最终完整路径。上传固定当次目标，不会随默认设置变化。目录重名时拒绝覆盖。生成 `data.yaml` 的 `path` 使用所选节点实际解析的目录，训练/验证 split 使用相对路径。
- “登记已有服务器目录”：选择父保存位置，填写已有文件夹名称。必须含 `data.yaml`，其中 `path` 指向本目录（可省略或为 `.`），`train/val` 为 `images/train`、`images/val`，图片与标签自包含；不会把服务器其他路径打包进来。远程登记经过 Agent 导出及平台完整校验，需要中转空间。
- 普通登记为“外部文件”，没有删除权。可在登记时明确接管，或在卡片“接管文件”中输入完整目录确认。
- “复制 / 迁移”：选择目标保存位置和名称，默认复制并保留源文件；明确勾选才在目标成功后删除源。仍有任务引用源时只能复制。支持本机↔远程与远程↔远程，中转由平台完成，Agent 无需开放入站端口。
- “删除”：先加载预检查，后台永久删除图片、标签和 YAML；引用任务（含历史 Attempt、回收站）必须先处理。远程未知 YAML 可能存在别名引用，平台会保守阻止删除，不凭路径不同推断安全。
- “操作记录”：全部目录检查、上传、登记、迁移、删除历史分页展示，详情中显示阶段、传输量、离线等待与具体失败原因；可重试当前阶段或在文件提交前取消。数据库保留全部操作记录，页面不再限制最近 200 条。

远程训练创建窗口支持上传至选定节点，也可从远程数据集路径输入框选择已登记数据集。仅服务器一致的数据集参与选择；本机资源列表包含已登记且可读取的本机目录。

## 上传续传与一致性

浏览器按文件流式计算 SHA-256，服务端核验每次上传字节与清单；断线后保留完整文件。关页后重新选择原文件夹，服务器位置、名称、逐文件内容指纹一致时才复用原上传。浏览器不能在关闭页面后继续读取本地文件；跨页面恢复需要浏览器存储可用，清空浏览器存储会失去原上传入口。

浏览器文件全部到达后，后台先生成快照、校验图片和标签，再传到目标节点。远程采用 512 KiB 分块，按已确认字节续传；文件 SHA-256 和整包 SHA-256 均核验。发布在目标同文件系统的隐藏兄弟目录完成，最后一次目录重命名才对训练可见。Agent 写入持久回执后才确认；丢失确认不会再次删除后来创建的同路径文件。

校验失败保留待重试文件并计入中转配额。提交文件前可取消；进入提交阶段即使报错也需要重试完成，避免把已落盘的目录当作从未发生。目标成功而源清理失败时，操作历史显示已保存目标路径，重试仅执行源清理。源文件发生变化时指纹校验拒绝删除。

## 配置与磁盘

平台 `.env`：

```dotenv
# 相对项目根解析；Linux 多个允许范围用 : 分隔。
PLATFORM_DATASET_STORAGE_ALLOWED_ROOTS=.
# 平台中转配额 100 GiB；0 仅禁用配额，仍保留剩余空间检查。
PLATFORM_DATASET_STORAGE_QUOTA_BYTES=107374182400
```

增加外部数据盘时，将其实际挂载目录加入白名单再在界面登记保存位置。不要写入系统根目录，不跟随请求路径中的符号链接。原有 `数据集`、`ultralytics/xl` 目录继续兼容；若部署将旧目录放在项目以外，也需要将其加入允许范围，才可用新管理接口迁移或删除。

Agent 配置（标准 JSON，中文说明放在 `_comments`）：

```json
{
  "dataset_roots": ["数据集"],
  "dataset_staging_quota_bytes": 107374182400
}
```

`dataset_roots` 相对 `training_cwd` 解析。旧真实配置未指定时默认为空列表，保持原来的监控/训练行为；要启用管理必须明确添加。启用训练时这些范围必须在 `allowed_training_roots` 内，否则配置检查报错，防止上传完成后训练无权读取。示例配置使用 `datasets`；两个独立分发包使用其原有训练白名单中的 `数据集`。两套平台的身份、数据库及真实配置不能混用。

平台中转目录为配置的 `PLATFORM_DATA_ROOT/dataset_storage`，浏览器原始文件暂存于 `PLATFORM_DATA_ROOT/dataset_uploads`。Agent 在配置文件旁 `.dataset-state` 保存分块与回执。目录内包含原始数据，请使用与平台数据相同的备份和访问权限。

50 GiB / 20 万文件为数据集上限；上传单图 256 MiB、文本 4 MiB。中转、校验展开及目标隐藏发布副本都消耗空间；平台准备快照至少预留约数据大小两倍及 100 MiB，每一接收端还检查当地磁盘余量。配额只约束中转文件，不限制所有已发布的数据集总大小。Agent 持有工作区锁和数据集根目录锁，既有训练运行时等待空闲，不会强制停止它。

完成/取消的中心中转与上传暂存保留至 24 小时后由后台回收；失败操作保留，以便排错和重试，可在可取消阶段取消再等待回收。Agent 成功确认后释放该次包文件，微小回执保留一天后在下一次成功操作时回收；未确认包保留断点且计入配额。

## 旧数据与引用

旧平台上传目录自动登记，旧客户端的上传和名称删除 API 保留；界面使用稳定 ID，支持不同服务器和位置下的同名数据。普通复制生成新 ID；源文件清理成功的迁移保留原 ID，并记录原服务器和路径历史。任务及历史 Run 的路径快照不会被批量改写。

删除/源清理持久排队后，节点训练领取及任务引用变更会被阻止；执行前再次核验引用，Agent 再通过工作区锁保护真实文件。任何活动训练存在时拒绝清理，以免未登记的路径别名造成误删。旧目录第一次删除先在后台建立内容指纹；新目录沿用已校验指纹。

## 升级与验证

平台启动通过元数据创建 `dataset_locations`、`dataset_entries`、`dataset_operations` 三张新表，保留原有表和数据。更新代码和前端依赖后运行 `npm ci && npm run build`；安排开发版后端重启，新路由与后台操作才生效。应用升级不会自动修改任何实际数据集保存目录。

远程数据集管理最低 Agent 2.1.0；原有远程训练兼容门槛保持不变。训练空闲时更新远程脚本并合并新增配置，保留 Token、节点 ID、中心地址、原路径、`.training-state/` 和 `.dataset-state/`，执行 `--version`、`--check-config` 后重启对应 Agent；旧中心缺少数据集 API 时新 Agent 兼容跳过轮询。

实现测试使用隔离临时目录和模拟 Agent 协议，覆盖本地及跨节点上传/迁移/删除、稳定 ID、旧目录、外部接管、引用保护、坏 SHA、符号链接与归档穿越、取消、离线等待、提交响应丢失和删除中断恢复。未对正在使用的训练数据做试删；不自动更新或重启使用版。
